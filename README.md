## How to Work on HTML/JS Projects

When working on these, you'll want a browser window open alongside your editor.

I strongly recommend running `uvx livereload`, which (assuming you have uv installed)
will launch a local web server that will reload your changes as they're saved.
**You will still need to refresh the browser using Ctrl-R or Cmd-R to see the changes reflected.**

You will usually want to keep the browser's developer console open as well, so you can see error messages and debugging output.
There will be a brief tutorial on using the console in class.

Similar to the tutorial style from the first lab, the instructions are mostly inline in comments/etc. --
be sure to read these comments carefully as you work your way through each problem!

## Note on Data Loading (for Part 2)

In part two, if you aren't using a web server you will run into browser restrictions on loading data from files.

Either use `livereload` as shown above, or `python -m http.server`
